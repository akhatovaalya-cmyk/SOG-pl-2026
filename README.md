# P&L агент — Saurida Oil & Gas (СОГ)

Streamlit-приложение: загрузка выгрузки 1С ОСВ → P&L.
Доход по контрагентам, затраты по статьям (7010+7110), админ 7211 расшифрован,
7212 отдельным блоком, налоги с ЗП свёрнуты. Сверка с 1С (контроль «Разница» = 0).

## Файлы
- `app.py` — интерфейс (Main file path для Streamlit)
- `sog_engine.py` — парсер ОСВ + генератор P&L + журнал
- `recalc_native.py` — пересчёт формул
- `requirements.txt` — зависимости
